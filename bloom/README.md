# Bloom

A calm app for teens about sleep, mood, stress and growing up.
School project, Moscow State School №1535.

## Что где лежит

| Файл | Что внутри |
| --- | --- |
| `lib/content/articles.dart` | Статьи для вкладки «Узнать». **Сюда пишите свои тексты.** |
| `lib/l10n/strings.dart` | Все надписи приложения на английском и русском |
| `lib/theme.dart` | Цвета приложения (светлая и тёмная тема) |
| `lib/main.dart` | Название приложения (`appName`) |
| `lib/screens/` | Экраны приложения |
| `.github/workflows/build.yml` | Автоматическая сборка APK на GitHub |

## Как получить APK

После каждого изменения файлов на GitHub сборка запускается сама (вкладка **Actions**, около 5–8 минут).
Готовый файл появляется на странице **Releases** репозитория: откройте последнюю версию и скачайте `Bloom.apk`.
